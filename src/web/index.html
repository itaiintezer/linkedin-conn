    Event invites

    An event run reserves this many minutes of the day for itself, and the send planner routes connection requests and messages around the window. Locations are worked densest-first; whoever is left over rolls into the next day’s run.

    Post engagements

    A reaction is cheap; a comment is public and attributable, so it gets its own daily ceiling. Once today’s comment budget is spent the engine keeps reacting and leaves the comment for another day — it never drops one silently.

    Profile enrichment

    Runs by itself: anything not yet enriched is picked up within a minute, so newly-discovered connections fill in without being asked. Scrapes each profile via Apify — location, current role, full history and skills — on Apify's infrastructure, never your LinkedIn session, so it isn't paced or capped.

    Stored locally and never returned by the API. Get one at console.apify.com → Settings → Integrations.

    Paste your LinkedIn Connections.csv export, or just a list of profile URLs. Re-importing the same file updates existing entries rather than duplicating them. To get the export, on a desktop browser: Settings & Privacy → Data privacy → Get a copy of your data → the larger archive that includes connections. LinkedIn emails a download link in about 24 hours.
